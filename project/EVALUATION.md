## ค่าที่ใช้

เกณฑ์ L1 คือ 7 A · L3 ใช้ alpha 0.3, k 6, minSamples 5, sdFloor 0.05

เลือกค่า `k` ด้วยการไล่ทดสอบกับชุดข้อมูลนี้ และตรวจว่าผลยังคงเหมาะสมเมื่อใช้หลาย seed ไม่ได้เลือกตามความรู้สึก ทำซ้ำได้ด้วยคำสั่ง:

```bash
for k in 3 3.5 4 4.5 5 6 8; do EVAL_K=$k npm run evaluate; done
for s in 42 7 99 2026; do EVAL_SEED=$s npm run evaluate; done
```

## วิธีอ่านผล

L1 ใช้เกณฑ์คงที่ 7 A ดังนั้น Recall ของ `subtle_waste` จึงเป็น 0 ตามการออกแบบ เพราะข้อมูลกลุ่มนี้ถูกสร้างให้ต่ำกว่าเกณฑ์โดยตั้งใจ ส่วน L2 และ L3 เปรียบเทียบค่าที่อ่านได้กับพฤติกรรมเดิมของห้อง จึงตรวจจับกลุ่มนี้ได้ การตรวจจับที่เพิ่มขึ้นมาพร้อม false positive ซึ่งแสดงไว้ในคอลัมน์ FP

หากยังไม่มี L4 ให้อธิบายระบบว่า *rule-based + statistical anomaly detection* ไม่ใช่ machine learning
